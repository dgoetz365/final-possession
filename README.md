# Final Possession

A college basketball draft and coaching game. Build a twelve-player roster, set your rotation, and coach the important moments of a 64-team tournament.

**[Play the live game](https://final-possession.danielgoetz301.chatgpt.site)** · [About Dan Goetz](https://dangoetz.me)

This is a personal sports simulation using historical player records, not a prediction of real games.

## Play on another computer

1. Download [Final-Possession-Complete-2026-10-16.zip](Final-Possession-Complete-2026-10-16.zip) using the download button on its file page.
2. Extract the ZIP into a normal folder.
3. Open **Final Possession.html** in your browser.

The portable game needs no installation or internet connection. Fonts, artwork, game logic, and the bundled player records are included.

For the game alone, download [Final-Possession-Portable.html](Final-Possession-Portable.html) and open the downloaded file in your browser.

## What's included

- **Portable HTML:** the playable offline game.
- **Complete ZIP:** the portable game, full application source in `source/`, tests, setup instructions, and font licenses.
- **START HERE.txt**, inside the ZIP: instructions for playing, transferring saved runs, and running the source project.

This version uses bundled historical player data. The complete source includes the separately configured server integration for live imports. Credentials and local runtime state are excluded.

## Move an existing run

In the original game, open **Settings > Export save**. Transfer that JSON file to the other computer, then use **Settings > Import save** in the downloaded game. Export your run before moving the HTML file or changing browsers.
